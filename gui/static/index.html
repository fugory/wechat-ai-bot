删表情（需手动）

自动删除做不到：微信会过滤合成输入，我们点「删除」菜单项没有任何反应（ Invoke / 真实鼠标 / 键盘都试过）。
怎么删：打开微信表情面板 → 收藏 → 滚到底 → 右键那张 → 删除， 然后回这里点「从微信收藏同步」。
面板一页只显示 25 格，收藏超过 25 个时，多出来的会排到第二页（发送时需要滚动，较慢）。
表情来自微信收藏：这里不支持批量导入文件，只支持 模型自动收集（群里看到合适的新表情自动收）或手动添加 （在微信里右键表情 → 添加到表情，再点上面的「从微信收藏同步」）。 新接入的账号如果已有收藏，同步后会自动补描述。

面板视图（和微信一致：5 列，最新在左上）

每一格对应微信表情面板里同一位置的格子。点某格 = 发送时点那一格。
微信规则：先收藏的排在后面，所以左上角是最新收藏，右下角是最早收藏。
